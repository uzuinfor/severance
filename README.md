# 💰 스마트 퇴직금 & 퇴직소득세 계산기 (Smart Severance Calculator)

대한민국 근로기준법 및 최신 세법 규정을 충실히 반영하여 개발된 프리미엄 **퇴직금 및 퇴직소득세 계산기** 웹 서비스입니다. 

로딩이 빠르고 설치가 필요 없는 순수 HTML, CSS, JavaScript(Vanilla JS)로 설계되었으며, 모던하고 아름다운 글래스모피즘(Glassmorphism) 테마를 탑재했습니다.

## 주요 기능

1. **실시간 평균임금 산정 및 퇴직금 계산**:
   - 퇴직일(마지막 근무일의 다음 날)을 기준으로 직전 3개월의 실제 월별 일수(역일수)를 자동으로 일수 분할하여 입력 폼을 제공합니다.
   - 상여금(3/12 반영) 및 연차휴가 미사용수당(3/12 반영)의 법정 가산액 처리를 지원합니다.
2. **통상임금 보장제 적용**:
   - 입력한 월 통상임금 기준 1일 통상임금과 평균임금을 자동으로 비교하여, 근로기준법 제2조 제2항에 따라 더 높은 금액을 기준으로 최종 퇴직금을 계산해 줍니다.
3. **최신 퇴직소득세 모의 계산 (2025/2026)**:
   - 근속연수별 공제액 및 환산급여 공제율을 반영한 세액 시뮬레이터입니다.
   - 개인퇴직연금계좌(IRP)로 수령 시 세액 감면 혜택(30%~40%)에 따른 실령액 모의 조회를 제공합니다.
4. **인쇄 및 PDF 다운로드 최적화**:
   - 계산된 최종 상세 명세서 서식을 지면이나 PDF 파일로 아름답게 보관할 수 있도록 프린트 전용 미디어 쿼리가 적용되어 있습니다.
5. **다크 모드 & 기록 보존**:
   - 눈을 편안하게 해주는 다크 모드 전환 기능과 최근 5개 계산 내역을 브라우저에 자동 보존(`localStorage`)하는 기능을 제공합니다.

git remote add origin https://github.com/gloriajung1106-art/fund.git

# 코드 업로드 (첫 푸시)

### 3. GitHub Pages 배포 활성화
1. 웹 브라우저로 자신의 GitHub 저장소인 [gloriajung1106-art/fund](https://github.com/gloriajung1106-art/fund)에 접속합니다.
2. 상단 탭에서 **Settings**를 클릭합니다.
